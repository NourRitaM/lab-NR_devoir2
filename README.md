# The Echoes of Akatsu

The Echoes of Akatsu is a responsive fantasy adventure game website created as part of a web development assignment.

## About the Project

The website presents the world of Akatsu, a mysterious fantasy kingdom filled with forgotten magic, ancient relics, and hidden secrets. The player follows Ming Yi, a young apothecary searching for her missing sister.

## Pages

- `index2.html` - Homepage and game presentation
- `character.html` - Character presentation
- `About.html` - About the creator and contact form

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive design

## Features

- Responsive layout for mobile and desktop
- Navigation between pages
- Fantasy game story presentation
- Character information
- Contact form
- Social media links
- Responsive sidebar and footer

## How to Open the Project

Open `index2.html` in a web browser.
